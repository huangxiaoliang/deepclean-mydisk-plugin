# 文案术语表（UI 与报告统一用词）

> 适用范围：`lib/client.js`、`lib/index.js`、`lib/clean.js`、`resources/scripts/**` 中所有面向用户的中文文案；英文译名在 `lib/client.js` 的 EN 表成对维护。
> 规则：新增或修改文案先查本表；术语变更需同步更新本表、EN 表与 `tests/` 中的断言。

## 术语

| 概念 | 统一用词 | 说明 |
|---|---|---|
| 扫描动作 | 扫描 | 开始扫描 / 重新扫描 / 正在扫描… / 扫描结果 / 扫描结果已过期；快速扫描 / 完整扫描 |
| 功能名 | 体检 | 仅用于导航与首页标题（磁盘体检），不作动词 |
| 清理目的地 | 废纸篓（macOS）/ 隔离区（Windows 与其他平台） | 按平台选词，不并列「废纸篓/隔离区」 |
| 保护机制 | 保护名单 | 加入保护名单 / 受保护 / 保护名单文件；不用「白名单」 |
| 可清理总量 | 预计可释放 {size} | 不用「可处理 / 可回收 / 建议处理」 |
| 风险档位 | 推荐清理 / 可选清理 / 需确认 / 受保护 | 报告章节对应「不建议清理」，不用「不要动」 |
| 跨盘移动 | 移动 | 移动到… / 正在移动 / 移动完成；不用「搬家」；确认层说「移动到其他磁盘」 |
| home 目录 | 个人文件夹 | 不用「家目录」 |
| 企业微信 | 企业微信 | 不用「企微」 |
| 影响说明 | 清理影响 | 列名与详情字段统一 |

## 句式与风格

- 陈述句、不缩写：用「需要时会重新下载」，不用「重下」「可删」。
- 不向普通用户暴露实现细节：SHA-256、退出码、内部批次 ID 不进提示文案（SHA-256 只出现在设置页安全说明）。
- 错误文案说明「发生了什么 + 怎么办」，不堆砌技术名词。
- 中西文混排留一个半角空格；数字单位统一「300 MB / 1.5 GB」（数字与单位之间一个半角空格）。
- 中文语境用直角引号「」与全角省略号 …；并列分隔统一用「·」。
