# 文案术语表（UI 与报告统一用词）

> 适用范围：`lib/client.js`、`lib/index.js`、`lib/clean.js`、`resources/scripts/**` 中所有面向用户的中文文案；英文译名在 `lib/client.js` 的 EN 表成对维护。
> 规则：新增或修改文案先查本表；术语变更需同步更新本表、EN 表与 `tests/` 中的断言。

## 术语

| 概念 | 统一用词 | 说明 |
|---|---|---|
| 扫描动作 | 扫描 | 开始扫描 / 重新扫描 / 正在扫描… / 扫描结果 / 扫描结果已过期；快速扫描 / 完整扫描 |
| 目录分布统计 | 目录统计 | 重新统计 / 目录统计已过期 / 来源：目录统计；与「扫描」区分：扫描指体检（scan.py），目录统计指空间页目录分布（tree.py） |
| 功能名 | 体检 | 仅用于导航与首页标题（磁盘体检），不作动词 |
| 清理目的地 | 废纸篓（macOS）/ 隔离区（Windows 与其他平台） | 按平台选词，不并列「废纸篓/隔离区」 |
| 保护机制 | 保护名单 | 加入保护名单 / 受保护 / 保护名单文件；不用「白名单」 |
| 可清理总量 | 预计可释放 {size} | 不用「可处理 / 可回收 / 建议处理」 |
| 目录内可清理部分 | 其中可清理 {size} | 空间页目录明细角标，仅基于新鲜体检报告显示；点击跳清理页预筛选 |
| 风险档位 | 推荐清理 / 可选清理 / 需确认 / 受保护 | 报告章节对应「不建议清理」，不用「不要动」 |
| 跨盘移动 | 移动 | 移动到… / 正在移动 / 移动完成；不用「搬家」；确认层说「移动到其他磁盘」 |
| home 目录 | 个人文件夹 | 不用「家目录」 |
| 企业微信 | 企业微信 | 不用「企微」 |
| 影响说明 | 清理影响 | 列名与详情字段统一 |
| AI 只读解释 | 问 AI / 让 AI 解读这次体检 / 让 AI 分析趋势 / 复核这 {n} 项 | 只做解释与建议；文案不出现「自动清理」「AI 已清理」；入口不可用时提示复制提示词 |
| 未收录项 | 未收录 | 扫描器名称表没有该应用，名称回退为 bundle id；不暗示不可清理 |
| 历史复清 | 清了又长回来 | 仅当当前新鲜报告里仍存在、且回到清理时 30% 以上时出现 |
| 恢复动作 | 恢复 / 撤销 | 「恢复此批次」用于历史（跨重启）；「撤销」用于本次会话；不用「还原」「回滚」 |
| 恢复冲突 | 另存为副本恢复 | 原位置已有同名文件时，恢复为「名称 (restored)」，不覆盖原文件 |
| 审计失败 | 历史里可能看不到恢复记录 | 审计日志写入失败时的固定说明；不承诺「可在历史恢复」 |
| 释放（第二阶段） | 永久删除 | 清理只是「移出」；「永久删除本批次 / 永久删除全部」才真正释放空间；不用「彻底清理」 |
| 隔离区占用 | 隔离区/废纸篓：{size} 可释放 | 首页/历史固定说法；Windows 额外说明「不在回收站」 |
| 云盘文件 | 云盘文件不参与搬家/去重 | 云盘（iCloud/OneDrive/Dropbox/Google Drive）文件搬走会同步删除云端 |
| App 数据目录 | App 数据目录内的文件不允许搬家 | 照片图库、Mail、Messages、应用容器、商店应用数据；说明「可能破坏应用数据」 |
| 分批 | 将分 {n} 批执行（每批最多 200 项） | 单次超过 200 项时由服务端分片；一次操作可能生成多个可恢复批次 |
| 残留细分 | {App} · 缓存 | 从「需确认」残留里拆出的缓存子目录行（可清理）；原残留行说明「其中缓存子目录已单独列出（可清理）」，其余数据仍只读 |

## 句式与风格

- 陈述句、不缩写：用「需要时会重新下载」，不用「重下」「可删」。
- 不向普通用户暴露实现细节：SHA-256、退出码、内部批次 ID 不进提示文案（SHA-256 只出现在设置页安全说明）。
- 错误文案说明「发生了什么 + 怎么办」，不堆砌技术名词。
- 中西文混排留一个半角空格；数字单位统一「300 MB / 1.5 GB」（数字与单位之间一个半角空格）。
- 中文语境用直角引号「」与全角省略号 …；并列分隔统一用「·」。
